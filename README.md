# ИСКРА — лендинг лимонада

Ещё один проект в портфолио. Придумал несуществующий бренд крафтового лимонада и сделал для него рекламный одностраничный сайт. Хотелось чего-то яркого и весёлого, в противовес строгому сайту про iPhone.

**Посмотреть:** https://azer1xxx1337.github.io/iskra/

## Что тут есть

- 3D-банка на первом экране — крутится сама, можно покрутить мышкой, на ней капли конденсата.
- Четыре вкуса: грейпфрут-розмарин, огурец-мята, облепиха-имбирь, черника-лаванда. При выборе вкуса весь сайт плавно перекрашивается в его цвета, а банка делает оборот и меняет этикетку.
- Этикетки не картинки — они рисуются кодом на canvas, поэтому их легко менять.
- Пузырьки на фоне, бегущая строка, разделы «Состав», «Вкусы» и «Как делаем».
- Конструктор набора: собираешь коробку из 12 банок, цена и скидка считаются сразу.
- Адаптив под телефон.

## Как сделано

HTML, CSS и чистый JavaScript, без фреймворков. 3D — на Three.js (r128): банка собрана из цилиндра и двух фигур вращения для крышки и дна. Плавная смена цветов сделана через CSS-переменные с `@property`.

## Запустить у себя

Просто открыть `index.html` в браузере.

## Важно

Бренд, цены и цифры в составе выдуманы — это концепт, а не настоящий магазин. Кнопка заказа ничего не отправляет.
